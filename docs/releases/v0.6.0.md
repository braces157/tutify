# Tuitify v0.6.0

Use your Spotify library and discovery with matched Volta lossless audio, or open
the standalone Volta catalog. Automatic launch prefers connected Volta with
FFmpeg, then Spotify Premium, then free YouTube Music.

Create a personal Volta application and run `tuitify volta login`. The secret is
entered without echo and stored in Windows Credential Manager. Each user supplies
their own credentials; the release contains no shared application secret.
See [Volta setup](https://github.com/braces157/tutify/blob/v0.6.0/docs/volta.md)
for permissions and commands.

Spotify-to-Volta resolution tries the ISRC recording identifier first, then strict
title, artist, version and duration matching. Missing or ambiguous matches report
an error and preserve the Spotify queue. Standalone Volta keeps separate state.
Choose `tuitify --source spotify` or `tuitify --source youtube` explicitly when
you want those audio providers.

Playback and Discord presence show the available source codec, resolution and
bitrate. Volta requests its highest available lossless stream; the Windows shared
audio output can still resample it. This is not a bit-perfect output claim.

Repository history, staged source and extracted release contents are checked with
Gitleaks, including Volta-specific secret detection. Local agent notes, work logs,
credential files and development captures are excluded from publication.

See [validation](https://github.com/braces157/tutify/blob/v0.6.0/VALIDATION.md)
for automated coverage and live-test limits.

Download `tuitify.exe` or `Tuitify-0.6.0-windows-x86_64.zip`. SHA-256 sidecars and
`Tuitify-0.6.0-windows-x86_64.manifest.json` identify the published assets.
