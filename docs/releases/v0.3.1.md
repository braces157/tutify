# Tuitify v0.3.1

This update repairs Vietnamese Radio matching and duet lyrics, completes mouse
controls in Statistics and Mix Builder, and reduces work when saving large queues
or refreshing listening statistics.

## Changes

- **Vietnamese Radio:** match Latin accent aliases across catalogs only after
  confirming the seed recording. Exact-name preference and artist-ID checks remain.
- **Duet lyrics:** retry a missing full-credit lookup with the verified primary
  artist. Keep Unicode accents, normalize equivalent Unicode sequences, and check
  the returned title, artist, and duration before displaying the fallback.
- **Lyrics outages:** retry HTTP 502–504 once with a short wait, honor longer
  cooldowns, and show concise service errors. F5 retries in the lyrics view.
- **Mouse controls:** select, scroll, search, and sort Statistics; use Mix Builder
  preferences, pins, details, and recipe actions. Wrapped controls and long names
  retain correct hit regions. Enter replaces a queue; Shift+A appends.
- **Saved data:** stop startup on invalid statistics or recipes, preserving the
  original files. Buffer atomic JSON writes and avoid duplicate snapshot clones.
- **Responsiveness:** normalize statistics titles once, sort once, update metadata
  per track, and correct Glass idle/debounce refresh deadlines.
- **Audio visualization:** map frequency bands using the actual output-device rate.
- **Artist browsing:** validate requested artist IDs and limit the restricted
  endpoint fallback to HTTP 403.

## Verification

Windows x64, Rust 1.95.0: 363 automated Rust tests passed, with 16 environment or
benchmark opt-ins excluded from the regular suite. Formatting and strict Clippy
passed. Website checks and packaging are recorded in
[VALIDATION.md](https://github.com/braces157/tutify/blob/v0.3.1/VALIDATION.md).

Live catalog checks returned 14 suggestions for **Mưa — Minh Vương M4U, Thùy Chi**
and 15 for **Castle on the Hill — Ed Sheeran**. Live LRCLIB checks returned 59 and
49 synced lyric lines respectively. These checks used live services without audio
or saved-state writes; provider coverage can change and queue sizes are not guaranteed.
New live-audio or output-device switching acceptance was not performed for this release.

## Install and upgrade

Download `tuitify.exe` or `Tuitify-0.3.1-windows-x86_64.zip`; SHA-256 files accompany
both downloads. The ZIP includes guides, release notes, and `scripts/install.ps1`.
Run the installer to put the player on your user PATH.

Quit and reopen Tuitify after upgrading. Start a fresh search or press R to
generate new Radio suggestions; restoring an old queue retains its existing tracks.
Open lyrics with l and use F5 to retry. Settings and saved-state formats are unchanged.

Windows 10/11 x64 and Spotify Premium are required for playback. The native demo
(`tuitify demo`) requires no Spotify account or audio device. Related-artist
suggestions are supplied by Deezer and verified in Spotify; they do not reproduce
Spotify's private personalization or guarantee a song's language, mood, or energy.
