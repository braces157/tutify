Quickstart

Install Tuitify in Seconds

Pick your preferred installation method below.

Download the pre-compiled, self-contained Windows executable directly from the GitHub Release. No Rust toolchain or external dependencies needed.

Download tuitify.exe (v0.2.3) Download .ZIP Package (v0.2.3)

Place tuitify.exe in your %PATH% (e.g. C:\Users\<You>\.cargo\bin\) and type tuitify in any terminal!

If you have Rust installed, install or update directly via Cargo:

cargo install --git https://github.com/braces157/tutify.git

Builds optimized release binary with ThinLTO and stripped symbols.

Run this single command in Windows PowerShell to download the latest binary directly to your local user directory:

iwr -useb https://github.com/braces157/tutify/releases/latest/download/tuitify.exe -OutFile tuitify.exe; .\tuitify.exe

First run opens two Spotify authorization steps: one for catalog access and one for streaming. Sign in with the same Spotify account in both browser prompts. The demo above is silent and does not open either login.

FAQ

Frequently Asked Questions

How do the synced lyrics work? Do I need a Genius or Spotify token? +

No extra token or API key is required! Tuitify connects directly to Lrclib (lrclib.net), the largest open synchronized lyrics database. It downloads millisecond-accurate timestamps and highlights lines in real time alongside your playback.

What color themes are included in v0.2.3? +

Tuitify comes with 5 curated themes: Classic Spotify (signature neon green), Phosphor Green CRT (vintage P1 phosphor terminal), Amber Terminal CRT (warm DEC VT220 amber), Monochrome Silver (high-contrast minimalist grayscale), and Cyberpunk Neon (electric cyan, magenta, and yellow). Press t to cycle anytime.

Do I need Spotify Premium to use Tuitify? +

Yes. Native Vorbis streaming via the Spotify Connect / Librespot audio key protocol is restricted by Spotify to Premium accounts. If your account does not have Premium, the API will refuse track key requests.

Does Tuitify require the official Spotify desktop app to be installed? +

No! Tuitify is 100% standalone. It decodes and plays audio directly to your Windows default audio endpoint using Rodio and CPAL without any Electron process running in the background.

How does authentication work? Is my password safe? +

Tuitify uses standard OAuth 2.0 PKCE. On first run, it opens two secure Spotify authorization pages in your browser: one for catalog access and one for streaming. Use the same Spotify account for both steps. Tuitify never sees or stores your Spotify password. The resulting access and refresh tokens are encrypted using Windows DPAPI and stored in Windows Credential Manager.
