Download the v0.5.0 Windows x64 executable. No Rust toolchain is needed. Spotify playback requires Premium; free music uses public YouTube videos. Missing playback tools are prepared on first launch; music search needs Python 3.10+.

Download tuitify.exe (v0.5.0) Download .ZIP package (v0.5.0)

Extract the ZIP and run .\scripts\install.ps1 to install for your Windows user and add Tuitify to PATH. Open a new terminal, then run tuitify anywhere.

Build the same v0.5.0 release with current stable Rust, the MSVC C++ build tools, and the Windows SDK:

cargo install --locked --git https://github.com/braces157/tutify.git --tag v0.5.0

Uses the v0.5.0 tag and its locked dependencies.

In Windows Terminal, open the folder where you want to keep the player. This downloads v0.5.0 into that current folder and opens the automatic player:

iwr -useb https://github.com/braces157/tutify/releases/download/v0.5.0/tuitify.exe -OutFile tuitify.exe -ErrorAction Stop; .\tuitify.exe

Run tuitify demo for the native TUI with isolated fictional data and simulated playback. A normal launch chooses Spotify for a connected Premium account or free YouTube Music otherwise. F6 connects accounts; use the same Spotify account in both Spotify authorization steps. Later launches restore the queue paused. The browser demo above is a separate, silent simulation.

Before the first play

A few things
to know.

Still curious? Read the full README ↗

Do I need Spotify Premium?

Only for Spotify audio. Run tuitify without Premium and it opens free YouTube Music automatically. Playback uses public videos, which YouTube may block or restrict on some connections. The native demo needs no account or audio device.

Does Spotify Desktop need to be open?

No. Tuitify streams and plays audio directly. Windows media keys work while you’re doing something else.

How does sign-in work?

Public music search needs no login. F6 Tools connects Spotify or a Google music library and returns to the player. Use the same account for both Spotify authorizations; tokens stay in Windows Credential Manager. Google library credentials are encrypted for your Windows user; library sign-in does not unlock restricted videos.

Where does my data go?

Preferences, queues, and listening totals stay on your PC. There’s no analytics collection. Discord presence is enabled by default and shares song details with your local Discord client. Read about data and privacy ↗
