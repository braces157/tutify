02 / Capabilities

Everything needed to stay in flow.

Tuitify keeps discovery, playback, queue decisions, lyrics, and system controls inside one responsive terminal interface.

🎨

Five terminal themes

Press t to move between Spotify, Amber, Matrix, Cyberpunk, and Monochrome. Each palette uses one dominant accent with a complete neutral ramp, and your selection persists between sessions.

Themes 5 semantic palettes
📊

Real-time FFT spectrum

Toggle the terminal spectrum with v. The Rust app transforms PCM samples from the playback worker into real frequency bands; the silent browser mock remains synthetic.

Behavior Pauses when idle
🎤

Synchronized lyrics

In the terminal player, press l to fetch lyrics from LRCLIB. Timed lyrics follow playback; plain lyrics can be scrolled. The browser demo uses bundled samples and makes no lyrics requests.

Source LRCLIB · no extra key
📻

Track-seeded radio

Press R to start radio from the selected track. Suggestions arrive asynchronously, exclude IDs already in the queue, and identify the provider used.

Autoplay Smart Deduplication
⚡

Native Rust audio path

A focused Rust executable streams Vorbis audio through Librespot directly to the Windows audio endpoint, without bundling a web runtime.

Architecture Native Windows audio
🔍

Catalog and library search

Hit / or f to filter only loaded rows. In the terminal app, F2 searches Spotify and F3 scans saved Liked Songs and accessible saved playlists for matching titles and artists. Results arrive as the scan progresses; the browser demo uses a small sample catalog.

Evidence Covered by repository checks
🎛️

Inspectable mix builder

Press Shift+M to preview a mix from the queue or a playlist. Set duration and the desired share of listening time from suggestions; inspect source/seed details with ?, then replace or append with undo.

Included in v0.2.6Usage guide
↔

Smart Shuffle

The third shuffle mode marks suggestions and mixes them after every three original tracks. Related-artist discovery supplies Spotify-verified tracks, while artist spacing and recording deduplication keep the upcoming queue varied without moving the playing prefix.

Included in v0.2.6 · discovery upgraded v0.2.9How it works
💿

Native album & artist browsing

Press a to inspect complete album tracklists with track numbers, durations, and playability. Press A to discover top 10 artist tracks, or use track context menus.

CatalogNative v0.2.8 feature
🧭

Breadcrumb navigation stack

Navigate deep into albums and artists with dynamic breadcrumb trails (Search › Album › Artist). Press Esc to pop history, instantly restoring selection cursor and scroll position.

03 / Queue integrity

Your queue, with a way back

Recover queue edits and search beyond the songs already on screen.

Keep your queue after re-login

Signing back into the same verified Spotify account keeps your queue, order, saved position, and metadata cache. Switching accounts, an unknown prior account, or explicit logout clears the old queue and cache. Streaming reauthorization uses the same catalog account.

Undo queue edits

Press u or Ctrl+Z, or right-click the queue and choose Undo, to recover from removal, clearing, replacement, additions, reordering, shuffle, or radio. Restored queues are paused; press Space to resume. History lasts for this session, up to 10 snapshots and 100,000 track IDs combined.

Scan your saved library

F3 searches titles and artists across saved Liked Songs and accessible saved playlist tracks, removing duplicate track IDs. It needs a network connection and can take time for large libraries. F5 restarts the scan. Esc cancels while browsing; while editing, first press Esc to leave the input.

Library scans retain partial matches and label incomplete results after cancellation, errors, rate limits, inaccessible playlists, or scan limits. Each scan allows up to 100,000 unique tracks, 100,000 playlists, and 100,000 page requests. These features run in the terminal app; the silent browser demo remains a sample simulation. 06 / Install

Start with one executable.

Download the release, build from source, or use PowerShell.

Download the v0.2.9 Windows x64 executable. No Rust toolchain is needed. Spotify playback requires Premium and a working audio output; the native demo does not.

Download tuitify.exe (v0.2.9) Download .ZIP package (v0.2.9)

Extract the ZIP and run .\scripts\install.ps1 to install for your Windows user and add Tuitify to PATH. Open a new terminal, then run tuitify anywhere.

Build the same v0.2.9 release with current stable Rust, the MSVC C++ build tools, and the Windows SDK:

cargo install --locked --git https://github.com/braces157/tutify.git --tag v0.2.9

Uses the v0.2.9 tag and its locked dependencies.

In Windows Terminal, open the folder where you want to keep the player. This downloads v0.2.9 into that current folder and starts guided Spotify sign-in:

iwr -useb https://github.com/braces157/tutify/releases/download/v0.2.9/tuitify.exe -OutFile tuitify.exe -ErrorAction Stop; .\tuitify.exe

Run tuitify demo for the native TUI with isolated fictional data and simulated playback. A normal first run opens two Spotify authorizations; use the same account in both. Later launches restore the queue paused. The browser demo above is a separate, silent simulation.

Included in v0.2.8

Mix Builder, Album/Artist Browsing, and the native demo

The native demo uses fictional data and simulated playback with no Spotify credentials, network, Discord, or audio device. It bundles fictional album and artist catalog datasets for testing tracklists, artist top tracks, and breadcrumb navigation. Download v0.2.9 and run:

.\tuitify.exe demo

Press a to browse album tracklists, Shift+A for artist top tracks, or Shift+M for Mix Builder. Its first suggestion request intentionally fails; press g to retry and demonstrate graceful recovery. Demo state lasts for the session.

07 / Before you install

Clear answers, up front.

01

Spotify Premium is required

A Spotify Premium account is required for streaming playback. The silent browser simulation and native development demo require no Spotify account.

02

Spotify Desktop is not required

Tuitify decodes the stream and sends audio to the default Windows endpoint itself. It does not remote-control or depend on the official desktop client.

03

Your password never enters Tuitify

Authentication uses browser-based OAuth 2.0 PKCE. Tokens are stored through Windows Credential Manager; use the same Spotify account for both authorization steps.

04

Lyrics need no extra key

Synchronized lyrics come from LRCLIB. When timestamps are available, Tuitify follows the current line; otherwise it shows plain lyrics or a clear unavailable state.
